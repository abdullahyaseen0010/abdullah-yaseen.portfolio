# Abdullah Yaseen Portfolio

A modern portfolio website built with Next.js 15 App Router, React 19, TypeScript, and Tailwind CSS 4. It showcases development work, service offerings, project experience, and contact details in a clean, responsive presentation.

## Stack

- Next.js
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- lucide-react

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Notes

- The project includes a published resume PDF in `public/resume.pdf`.
- Metadata, sitemap, robots configuration, and social preview are set up for portfolio SEO.
- Environment variables should be kept in a local `.env.local` file and not committed.
